# SillyTavern 的输入状态提示主题

这是一个为 [SillyTavern](https://github.com/SillyTavern/SillyTavern) 设计的“打字指示器”美化拓展。它允许用户自定义角色在“输入中...”状态时显示的样式和文本，提供了多种内置的精美主题和高度可定制的选项。

## ✨ 功能特性

- **多种内置主题**：提供包括像素风、简约透明、可爱风等多种预设主题，即装即用。
- **完全自定义**：用户可以轻松修改现有主题的CSS，或者创建全新的主题。
- **自定义文本**：支持修改提示文本，可以使用 `{{char}}` 变量来动态显示角色名称。
- **方案管理**：支持新增、删除、导入、导出文本方案和主题样式，方便分享和备份。
- **位置调整**：可将指示器放置在聊天窗口的多个位置（如输入框上方或聊天区底部）。

## 🛠️ 使用方法

使用以下 URL 通过内置扩展管理器进行安装并启用即可：[https://github.com/Sanjs333/SillyTavern-TypingIndicatorThemes]

## 批量导入主题

刷新页面后，在插件 **工具 → 批量导入主题** 打开导入窗口；指示器主题、播放器主题、文本预设及气泡样式原有的“导入”按钮也使用同一个入口。

- **选择 ZIP 主题包**：一次选择一个包含多个主题的 ZIP，插件读取包内各层目录中的 JSON，无需手动解压。手机文件选择器即使只能单选，也可选一个 ZIP 批量导入。
- **选择整个文件夹**：一次选中主题所在文件夹，包含子文件夹，自动列出其中的 JSON / ZIP 内容。此入口取决于浏览器的文件夹选择支持；不支持时会提示改用 ZIP。
- 保留 JSON 多文件选择与分次追加；桌面端支持将 JSON / ZIP 拖入弹窗。载入后，在插件列表里直接点击勾选所需主题，无需按 Ctrl 或 Shift。
- 支持混合导入本插件的 **CSS / iframe 指示器主题、播放器主题、气泡样式、文本预设**。原来的单项导出文件仍可直接使用，无需转换。
- 支持 JSON 数组，以及包含 `themes`、`textPresets`（或 `presets`）、`bubbleStyles` 数组的合集；也支持 `{ "items": [...] }`。合集中的元素仍为原有单项 JSON 对象。
- 导入前可查看类别、来源与数量，并勾选需要的条目。相同 ID 或同类别同名项可选择 **都保留 / 跳过 / 覆盖**；默认创建副本，不静默覆盖原内容。覆盖保留原 ID，避免破坏绑定；若 ID 和名称分别命中不同项，或指示器/播放器类型冲突，会提示而不强行覆盖。
- 默认不切换当前主题，也不重载无关编辑框；可勾选“导入后启用各类型的最后一项”。**覆盖当前使用中的条目会更新其效果和对应编辑区**，有未保存编辑时请先保存或备份。
- 坏 JSON、格式不支持或读取失败的文件会单独列出，其他有效项仍可导入。每批最多 500 个 JSON 文件 / 条目，单个 JSON 不超过 10 MiB，所选文件总大小和解压后累计大小各不超过 50 MiB；更多文件请分批导入。

ZIP 支持普通、未加密的单卷压缩包（非 ZIP64），最多包含 5000 个文件/目录；只读取 JSON，不导入包内嵌套的 ZIP、图片或其他外部素材。主题若依赖额外素材，仍需按作者说明安装。

仅支持本插件可识别的 JSON 格式，**不支持任意其他插件的主题**。主题可能含 JavaScript，请只导入可信作者的文件。文件解析不会执行主题代码；启用或预览主题仍使用插件原有的运行机制。本功能无需更新播放器后端或安装额外依赖。

## 安装与更新

若使用插件内的音乐播放器，需要同时安装两个组件：

- **前端扩展**：在 SillyTavern 扩展管理器安装或更新本仓库。
- **播放器后端**：[g-player-proxy](https://github.com/Sanjs333/g-player-proxy)，安装在 SillyTavern/plugins/g-player-proxy；请按后端 README 启用服务端插件并安装依赖。
